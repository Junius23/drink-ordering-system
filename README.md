\# Drink Ordering System



\## 📖 Project Overview



Drink Ordering System is a full-stack web application developed using React, Spring Boot, MySQL, and Docker Compose.



This project provides a complete online drink ordering platform with user authentication, shopping cart management, order processing, image upload, and administrator management functions.



\---



\## 🚀 Features



\### User Functions



\* User Registration

\* User Login

\* JWT Authentication

\* Browse Drinks

\* Add Drinks to Cart

\* Place Orders

\* View Order History



\### Admin Functions



\* Admin Login

\* Drink Management

\* Upload Drink Images

\* Order Management

\* Dashboard Statistics

\* Product Availability Control
